### Current Work

I build robotics software where controller-facing C++, ROS 2 packages, motion planning,
AI inference, and deployment infrastructure have to behave like one production system.

| Area | Public signal |
| --- | --- |
| Robot runtime software | Controller-facing C++ components, Linux systems work, and developer API surfaces. |
| Industrial planning | OLP automation, factory-cell constraints, task evaluation, and motion-planning workflows. |
| Edge AI systems | ONNX graph optimization, quantization-aware evaluation, and performance measurement for constrained inference targets. |
| Delivery | Kubernetes, Docker, CI/CD, MLOps, release operations, and infrastructure for repeatable robotics workflows. |
